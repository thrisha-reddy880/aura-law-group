# Aura Law Group — Modern Legal Interface Portfolio

A premium, highly interactive corporate legal landing page website engineered from scratch using **semantic HTML5, advanced CSS3 custom property systems, and modular Vanilla JavaScript**. 

This project simulates a high-end, tech-forward law firm specializing in data privacy compliance, startup venture scaling, and intellectual property asset protection.

## ⚡ Technical Features Implemented

* **Dynamic Legal Vulnerability Risk Calculator Engine:** Implemented a customizable evaluation algorithm in JavaScript that loops through radio option selectors, checks active input validation parameters, and dynamically renders contextual legal advice metrics directly into the viewport layout without forcing page reloads.
* **Active UI Theme Switcher Framework:** Engineered root style overrides using CSS Custom Properties (`:root` variables mapped to specific HTML attribute indicators `[data-theme="light"]`) triggered with event listeners to transition typography and canvas color palettes cleanly.
* **Interactive Client Services Explorer System:** Configured lightweight JavaScript display state selectors to hide or reveal comprehensive sector breakdowns dynamically, reducing layout weight and improving the user experience (UX).
* **Multi-Tier Navigation & Dropdown Layout:** Designed a sleek, corporate absolute-positioned nested dropdown layout with strict z-indexing to keep active link routing pathways clear and modern.
* **📱 100% Fully Responsive Layout Grid:** Deployed modern CSS Media Queries adjusting elements dynamically from multi-column desktop arrangements to beautifully stacked, wrap-around layouts optimized for mobile displays and tablets.

## 🛠️ Local System Installation Instructions
1. Clone this repository down to your local operating system directory.
2. Open the main file root folder layout.
3. Double-click the `index.html` file to instantly launch and run the interface application natively inside your preferred web browser window.
